# Changes this fork makes to rsext4

This repository modifies `rsext4` as published by rcore-os/tgoskits under `fs/rsext4`. It started
from tag `rsext4-v0.9.2` (commit `bd0153f7d336e3106ea6fd78b3a7ef2fe256d906`) and tracks the `dev`
branch at commit `2c1eff6c7fdca948943b50c796b2c0d54430a028`, the commit `.github/fork-upstream.toml`
names; AGENTS.md says how the fork merges a later one. The Apache License,
Version 2.0, section 4(b), asks that modified files carry a prominent notice that they were
changed. This file is that notice: it lists every file the fork changes or adds, and why. A file
not listed here is upstream's, as of the tracked commit, unchanged.

## Fixes submitted upstream

Each fix is one commit, written to upstream's conventions so it can go upstream unchanged, and each
goes upstream as an issue and a pull request of its own, apart from a row marked "not offered
upstream". "Not yet filed" means the upstream issue or pull request does not exist yet. The fork
carries every change that each pull request in this table makes to `fs/rsext4`, as of the head the
table names for an open one, apart from the parts the table says it leaves out or a later fix
changes. Pull request 2839 also adds a StarryOS test, and pull request 2840 also updates a caller in
`ax-fs-ng`; both are other tgoskits packages.

Fixes upstream has merged are listed under "Fixes upstream has merged" below; since the fork
tracks a `dev` commit that holds them, their code here is upstream's own.

## Fixes upstream has merged

Upstream merged these fixes into `dev`, and the tracked commit holds them, so their code here is
upstream's own, except fixes 2d and 8, which merged after it and are marked below. No release carries them yet: the latest rsext4 on crates.io is still 0.9.2. Upstream
pull request 2865, also merged (`7f853bff4`), builds the fuzz targets in the tgoskits workspace
checks; it changes only tgoskits CI, so the fork has nothing of it, and its own `fuzz.yml` builds the
targets.

Two smaller fixes, which the fork took from upstream commit `dde4020be` ([pull request
2525](https://github.com/rcore-os/tgoskits/pull/2525)) before it tracked `dev`, are upstream's own

## Changes only this fork needs

These are not meant for upstream.

| files | why |
|---|---|
| `Cargo.toml` | the workspace-inherited `edition` and `thiserror` keys are resolved to the literal values of the tgoskits workspace, so the crate builds outside it; `spinning_top` is 0.4, where the workspace has 0.3, to keep the dependency current; the version is `0.10.0-partsfoundry.1`, a pre-release that cannot collide with an upstream release; `rust-version` is set to 1.95, the oldest Rust that builds upstream's code; `repository` names this repository, and `documentation` is dropped |
